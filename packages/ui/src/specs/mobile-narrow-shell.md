# 手机端窄屏壳层(Mobile Narrow Shell)规范

- 状态:进行中(工作区未提交)。
- 所有者:`packages/ui` 的窄屏分支(Web 界面)与 `apps/zcode-ios`(原生配对外壳)。
- 依据:[DESIGN.md](../../../../DESIGN.md)、[AGENTS.md](../../../../AGENTS.md)。

## 1. 范围与唯一判定

- 手机端有两个入口,共用同一套 Web 界面:iOS 应用 ZCodeRemote(原生配对外壳 + WKWebView 加载 `packages/web`)和手机浏览器。
- 窄屏的唯一判定是 `packages/ui/src/lib/narrowShellViewport.ts`。CSS 侧用 Tailwind `max-md:`(<768px)。JS 侧用 `useNarrowShellViewport()` / `isNarrowShellViewport()`，任一为真即窄屏:
  1. `/?lan=1`、sessionStorage `zcode:lan-remote-session`、或 iOS 注入的 `--zcode-native-trailing-inset`(局域网手机远控,不信任 WebView 报的 layout 宽度);
  2. `innerWidth` / `documentElement.clientWidth` / `visualViewport.width` 任一 ≤ 767;
  3. `min(screen.width, screen.height)` ≤ 767(layout 被报成桌面宽、整页缩放塞进手机时,只有屏幕短边仍是机宽);
  4. 粗指针且上述短边/可见宽已不够放下侧向子菜单;
  5. `matchMedia("(max-width: 767px)")`。
     WebView 里 matchMedia 可能停在 viewport 生效前的旧值;监听 `resize`、`orientationchange` 和 `visualViewport` 的 `resize`,避免首帧被卡住。不新增第二套判定;`isMobileViewport`、`isMobileActive` 现为常量 false,本规范不复活。
- ≥768px 且非 lan/触控窄屏的桌面与宽屏 Web:DOM 结构、布局、交互全部保持不变。
- 状态所有者不变:侧栏开合由 `useAppPanels` 的 `isSidebarVisible` 持有;设置页窄屏导航由 `SettingsPage` 的 `narrowNavOpen` 持有。只改表现,不新增 store,不增加写入路径。
- 窄屏专用 token 与全局触控样式集中放在 `packages/ui/src/styles.css` 的窄屏段落;组件内只用 `max-md:` 做局部调整。

## 2. 非目标

- 不引入底部 Tab:DESIGN.md 规定手机远控保持「单列 + 抽屉」,这也是主流 AI 应用手机端的结构。
- 不改 stream、snapshot、队列、重连等远控链路,不为手机另起 Host 或会话。
- 不引入新依赖;底部面板基于现有 `components/ui/dialog.tsx` 实现。
- 不在窄屏强改字号,沿用用户设置的 `--ui-font-size`(12–20px)。

## 3. 设计规则

- 不丢功能:所有入口照常渲染并沿用原事件处理;任何被重新安放的入口,都必须在第 6 节对照表里写明新位置。
- 触控:窄屏可点击控件的命中区不小于 44px(`size-11` / `min-h-11`)。这是仅限窄屏的稳定系统理由,桌面控件尺寸不变。视觉上须保持小尺寸的控件用伪元素扩大命中区,不改视觉尺寸(抽屉行内操作按钮、模型菜单的连接方式胶囊都只向上下延伸,命中高度补到 44px);扩出的命中区不得压到相邻控件。
- 字号只用 `text-ui-*`;可编辑输入框用 `text-mobile-input-safe`。
- 颜色只用语义 token;不用品牌渐变或大面积品牌色,品牌色只用于激活态、主操作和发送键。
- 圆角:抽屉和底部面板属于对话框类浮层,自由边用 `rounded-2xl`,贴屏幕的边用 `rounded-none`;内部内容从 `rounded-xl` 重新计级。菜单外壳仍为 `rounded-lg`,菜单项为 `rounded-md`。
- 层级:页面本身不加阴影;菜单与底部面板用 `shadow-md`,抽屉用 `shadow-lg`。
- 模型选择在窄屏 / 手机远控只有**一个**面板,禁止 provider 菜单 + 侧向 `DropdownMenuSub`。面板宽约 `100vw - 2rem`(左右各约 16px inset)、最多 `24rem`,锚定在输入栏上方,内容纵向滚动。最大高度在 Radix `available-height` 上再扣掉顶栏与安全区(`NARROW_ANCHORED_MENU_MAX_HEIGHT_CLASS_NAME`):向上弹出扣掉顶部安全区、`3.5rem` 顶栏和 `0.5rem` 间距,面板顶边落在状态栏、顶栏和 iOS 原生会话按钮下方,列表滚到顶时第一项可见可点;向下弹出扣掉底部安全区和 `0.5rem`;结果不超过 `available-height` 且封顶 `24rem`,极矮视口保底 `6rem`(此时优先保证菜单可用,可能压住部分顶栏)。宽高上限与单面板布局同属一个窄屏分支,类名不带 `max-md:`,宽度 ≥768px 的横屏手机与 lan 远控同样生效。每个 provider 是同一面板内的小节标题,模型是标题下的行:小节标题 12px(`text-ui-sm`)、中等字重、三级文字色(`text-foreground-subtlest`),与 14px 正文色的模型行拉开层级;有连接选项的 provider 由连接头兼任小节标题,名字与徽标(`labelBadge`)和普通小节标题同一套渲染与样式,不再多渲染一行同名标题。模型行与底部操作行不低于 44px:基础菜单项的 `max-md:min-h-11` 只覆盖 `<768px`,这些行再拼一条不带前缀的 `min-h-11`,盖掉行上自带的 `min-h-8`。连接头里的连接方式胶囊(`size="xs"` 的 `SelectTrigger`,20px 高)视觉尺寸不变,用伪元素上下各扩 12px,命中高度补到 44px,横向不扩;连接头行同样拼 `min-h-11`,胶囊垂直居中后上下正好各剩 12px,扩出的命中区落在本行内,不压相邻模型行。模型名和连接头里的 provider 名换行完整显示、超长单词可断开,不用省略号截断,不得被屏幕裁成半截。小节标题、行高、模型名、连接胶囊命中区四组类名见 `narrowShellPresentation.ts` 的 `NARROW_MODEL_MENU_*` 常量,与宽高上限一样不带 `max-md:`。`shouldFlattenModelProviderMenu()` 在该路径返回 `"flat"`,不渲染 `DropdownMenuSub`。`≥768px` 且非 lan/触控窄屏的桌面可保留侧向子菜单。
- 动效:抽屉水平滑入、底部面板自下滑入,统一 300ms + `ease-sheet`(`cubic-bezier(0.32, 0.72, 0, 1)`,强减速、无回弹);位移只挂在 `motion-safe:` 上,`prefers-reduced-motion` 下底部面板与遮罩只淡入淡出,抽屉直接开合。
- 安全区:顶栏补 `env(safe-area-inset-top)`,输入栏与底部面板补 `env(safe-area-inset-bottom)`,左右补对应 inset。

## 5. 验收场景

1. 390×844 视口:点抽屉按钮后抽屉滑入;点遮罩、选择任务后的开合行为与改动前一致。
2. 第 6 节对照表中的每个入口都有可见的到达路径,不依赖悬停、快捷键或桌面专属操作,并触发原有行为。
3. 打开任一对话框:以底部面板呈现,底边不被 Home 指示条遮挡,内容超高时可滚动。
4. 输入框聚焦、键盘弹出:输入栏始终可见,页面不缩放。
5. 1280×800 桌面:布局与改动前一致,`max-md:` 样式不生效。
6. Zai Light / Zai Dark、字号 12px 与 20px、`prefers-reduced-motion` 组合下:无溢出、无错层。
7. iOS:`PairingUITests` 全部通过;配对成功进入工作区时无白屏闪烁。

- 新增或移动入口时,先在本表登记,再改代码。验收场景 2 按本表逐行核对。
- 已知限制:手机 Safari 弹出键盘时 `env(safe-area-inset-bottom)` 不归零,输入栏与键盘之间会留出约 34px。App 内的 WebView 只忽略容器安全区,键盘弹出时底边离开 Home 指示条,不会出现这段空白。
- 原生外壳槽位:iOS 外壳在 atDocumentStart 注入 `--zcode-native-trailing-inset: 52px`。会话头(`max-md:`)、设置页窄屏顶栏、铺满视口的侧面板两个头部,右内边距都加上 `var(--zcode-native-trailing-inset,0px)`;手机浏览器和桌面端取 0,效果不变。以后新增带右上角入口的窄屏头部,也要加上。
- 构建:`packages/ui/src/styles.css` 用 `@source` 同时扫描 `packages/web/src`,只写在 web 包里的类名(如局域网配对页)也会生成。
